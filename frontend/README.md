# 超导量子自进化测控平台

可本地试用的量子校准界面，包含「对话式 Agent」「蓝图版工作流」「工作看台」三个入口。当前仅演示单比特和双比特校准；不连接真实后端、量子设备、通用AI或数值拟合服务。曲线、报告、质量阈值和实验耗时均明确标识为模拟数据。

## 本地启动

建议使用 Node.js 22.12 或更高版本，以同时运行 Vite 7 和 TypeScript 状态测试；开发与验收使用 Node.js 25.6.1。依赖由 `package-lock.json` 锁定，Vite 为 7.3.7。

```sh
npm ci
npm test
npm run build
node scripts/start-preview.mjs
```

打开 [本地演示](http://127.0.0.1:5286)。预览进程在终端输出PID，使用 `Ctrl+C` 停止；端口已占用会明确报错，不自动切换到其他端口。开发时可运行 `npm run dev`。

三个入口的完整地址：

| 入口 | 本地地址 | 可试用内容 |
| --- | --- | --- |
| 对话式 Agent | [http://127.0.0.1:5286/#chat](http://127.0.0.1:5286/#chat) | 规则指令、单/双比特计划、任务分析、模拟曲线和报告下载 |
| 蓝图版工作流 | [http://127.0.0.1:5286/#blueprint](http://127.0.0.1:5286/#blueprint) | 节点选择、阶段切换、缩放、观测、审批、重试、暂停与终止 |
| 工作看台 | [http://127.0.0.1:5286/#dashboard](http://127.0.0.1:5286/#dashboard) | 搜索、状态/机器/实验筛选、分页、创建、复制及任务记录导出 |

这些链接切换视图，三个入口共享当前任务。选择另一条任务可使用工作看台的任务名称或左侧最近工作流。刷新后恢复已保存的任务数据，初始选中第一条任务。开发服务器若需要同一端口，可运行 `npm run dev -- --port 5286 --strictPort`；预览与开发服务器不要同时占用该端口。


## v1.2 数据存储、实时参数与账号

- 本机持久存储：工作流、节点状态、事件和设置保存至 localStorage，对话、输入草稿和原始附件保存至 IndexedDB。单附件仍为 10 MB，全部对话附件共 100 MB；保存状态、错误与重试可见。不同网址/浏览器/设备不共享，清理站点数据会删除记录。工作区 JSON 备份仍仅包含工作流，重要附件可下载副本。
- 工作看台每条任务可“展开实时参数”；蓝图节点提供参数页和折叠入口，展示配置、单位、进度、次数、演示采样及原始 JSON，模拟运行过程中持续更新。尚未执行值明确标为示例。
- 登录支持两种公开演示账号：团队负责人 `leader` / `Leader123!`，工作人员 `operator` / `Operator123!`。会话在当前标签页内有效 8 小时，退出即撤销；存储不包含密码。
- 负责人可操作和审批所有任务、修改策略、导入和重置工作区。工作人员可查看团队结果，创建和操作自己的任务；新建采用异常审批，异常决定交由负责人。旧任务没有账号归属，仅负责人可操作；可复制为本人新任务。所有变更在 Gateway 层二次检查权限。
- 这是前端身份与权限演示，不具备服务端安全隔离；不要输入真实账号密码。后端同事按 BACKEND_INTEGRATION.md 接入正式认证、账号管理、共享数据库和实时事件。

试用：用工作人员登录→创建实验→展开参数并运行→暂停→对话中添加TXT附件并发送→看到已保存后刷新→退出并用负责人登录→查看同一任务并处理审批。

## v1.1 新增与修复

- 右上角太阳/月亮切换明亮或深色主题，刷新保留；三视图与设置窗口同步配色。
- 工作空间设置新增四个分类：外观与个人、实验偏好、数据管理、模型连接。默认机器与审批策略用于之后的新建表单；模拟时钟开关刷新保留。显示名称仅用于本地界面。
- 对话支持本地附件：PDF、TXT、MD、CSV、JSON，单文件不超过10 MB、每条消息最多5个。文本以纯文本预览，PDF不声称已解析。附件和对话按任务隔离，自动保存于本浏览器的 IndexedDB，刷新后恢复；文件不会上传，也不会触发真实模型理解。
- 数据管理支持JSON校验预览与合并导入，保留已有任务、重复来源跳过、导入运行中任务转为暂停。单文件不超过5 MB，合并后最多200条任务。备份包含工作流与事件，不包含对话、附件或个人设置。
- 模型提供方、模型名称与地址仅作为本地配置草稿；保存不代表连接成功。密钥需后端管理。
- 修正蓝图节点长名称与小屏显示，手机顶栏可直接打开设置；创建增加防重复提交；弹窗键盘焦点保持在窗口内。

试用建议：先切换主题，打开设置修改偏好并保存；在数据管理导出JSON再选回该文件，检查预览显示重复跳过；到对话页添加文本附件，预览后发送。完整实验仍可按下方路线运行。

## 建议试用路线

1. 在对话式Agent选择「生成校准计划」或「双比特 CZ 校准」，创建演示工作流。
2. 在蓝图中查看PDF对应的实验顺序、读取复测、单比特并列检查分支和CZ优化后的复测。
3. 在蓝图点击「开始运行」，体验暂停/继续、审批、重试和终止；工作看台每行菜单也可启动、暂停或恢复。每个执行节点约四个演示秒。
4. 新建异常场景，使用阈值策略等待人工决策，或使用自动策略观察一次自动重试。严格策略会在每个节点等待审批。
5. 在报告中查看模拟曲线和生成依据，导出HTML、Markdown或CSV示例。

审批接受当前结果并进入下一节点；重试重新执行当前节点，两者行为不同。终止的运行不能恢复。暂停及待审批期间不会累计演示运行时间。初始数据包含八条不同状态的示例任务，支持直接体验完整界面。

## 流程与数据

单比特流程含9个执行实例，双比特流程含上述前置步骤及8个CZ校准实例，共17个。`IqToProbability`、`CZXEBCal`的复测作为独立实例执行。单比特尾部 `T1Idle`、`T2CPMG`、`RB1QCal` 在PDF蓝图上为并列分支；模拟器按共享测控资源串行调度。`TTGAczDelicateG`保留PDF的 `CZ_width=60ns` 展示参数。

状态保存在当前浏览器的localStorage，刷新可恢复；最多保存200条任务。清除浏览器站点数据会清除演示记录。工作流写入失败时会拒绝本次变更并显示错误，保留已有数据；对话保存失败时会提示重试。演示数据不用于判断设备性能。

报告区分「示例预览·尚未执行」「阶段报告·流程未完成」与「模拟完成报告」。未执行节点的曲线仅为预览，不能视为已采集结果。蓝图指标、节点详情与报告共用同一套模拟数据选择器；异常属于实际触发节点，重试后的当前结果与历史异常记录分别保留。

## 代码与接入

- `src/lib/simulator.ts`：任务状态机、演示时钟及持久化验证。
- `src/lib/gateway.ts`：默认mock的适配器，可注入后续真实后端实现。
- `src/lib/useWorkflowStore.ts`：React数据入口，通过Gateway加载、订阅与操作任务；真实模式不启用模拟计时和重置。
- `src/lib/measurements.ts`：三个视图共同使用的演示参数、曲线、节点结果阶段和报告判定。
- `src/App.tsx`：三个入口及交互，通过 `useWorkflowStore(gateway)` 调用 Gateway，支持 `<App gateway={adapter} />` 注入适配器。
- `src/components/ChatReport.tsx`：规则驱动的演示对话、曲线和报告导出。
- `qa/simulator.test.ts`：独立状态不变量、流程顺序和持久化边界测试。
- [BACKEND_INTEGRATION.md](./BACKEND_INTEGRATION.md)：拟定接口合同、操作语义和联调验收要求。

UI 的任务加载与操作已经经过 Gateway；未传 `gateway` 时使用本地 mock。后端同事实现 `WorkflowGateway` 后，可在应用入口传入 `<App gateway={adapter} />`。目前没有真实后端实现，接口地址与协议尚未确定；注入任务适配器也不代表模拟图表、报告或规则助手已经成为真实服务。正式联调还须用服务端结果替代 `measurements.ts` 的模拟参数，并补齐鉴权、幂等、版本顺序、断线重连和错误处理，详见对接说明。

## v1.3 参数侧栏、角色工作区与 CSV

- 顶栏、工作看台任务行、蓝图“实时参数”和节点“参数”入口打开独立右侧悬浮侧栏。支持跟随执行、固定/切换节点、拖动左边界或左右方向键调宽、Esc关闭；对话视图也能使用。
- 负责人进入团队工作看台，显示待审批任务；工作人员默认“我的任务”。团队任务标明只读，复制为本人任务后可操作；共享对话也按任务归属限制编辑、清空和附件变更。
- 工作看台或设置→数据存储→“导出全部实验 CSV”：不受当前筛选影响，导出本浏览器仍保留的全部已运行任务。UTF-8 BOM适配Excel/WPS，50列长表以“记录类型”区分任务、节点、配置参数、模拟结果、事件。每行带任务ID，节点记录带节点ID，便于筛选关联。
- CSV包括运行、暂停、异常、完成及运行后终止的任务；未启动草稿和队列排除，未执行节点保留配置但无最终结果。包含当前状态、执行次数、耗时、阈值、单位和保留的事件，数值仍为演示值。
- 当前存储仅保留节点最新状态和有限事件；无法恢复已删除任务、被覆盖的历史重试测量或已裁剪旧事件。需要逐次测量历史时由后端提供不可覆盖的运行记录。

## v1.3.1 实时参数代码视图
参数侧栏默认以只读 JSONC 代码行呈现，包含行号、语法高亮、单位注释和实时变更标记。顶部可切换/固定节点，复制按钮复制完整源码，不含行号。未执行或采集中 results 为 null，禁止将预览值误作实测值；明暗主题均适配。
