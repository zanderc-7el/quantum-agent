# API-only 离线模拟验证

在 `frontend` 目录运行：

```powershell
npm.cmd run validate:api-only
```

PowerShell 会优先解析 `npm.ps1`；若系统禁用脚本运行，使用 `npm.cmd` 即可，无需修改执行策略。也可直接运行 `node qa/api-only/validate.mjs`。

验证程序用 32 所交付的《超导量子计算机测控软件系统接口设计(1)》中列出的路径和字段，模拟创建与查询校准记录、提交与查询任务、查询实验数据、请求取消。它从一条**合成** S21 曲线计算频率建议，并输出 JSON 结论。模拟器在进程内实现 `fetch` 接口，无网络连接、SDK 或真机依赖。

同一验证链已接入工作台的「接口验证台」页面。启动前端并登录演示工作空间后，可打开 `#api` 点击「运行模拟验证」，查看调用步骤、曲线和待确认的接口合同。

该程序验证的是客户端请求封装、成功/失败响应处理和结果解析。模拟数据由本项目生成，校准记录、独立任务、实验数据之间没有经供应方证实的执行关联；`code=0` 和 `code=200` 均按交付文档示例暂作成功处理。取消接口的文档示例是 `data=false`，不能据此判断设备已停止。所有状态值与实验参数均为演示值。

**当前不能据此认定完整自动校准已具备。** 后续需从 32 所取得并验证：状态枚举及终态、逐次扫描参数覆盖、运行结果关联键、取消后的设备停止确认、参数发布/回读/回滚、幂等与设备互斥。真机可用后，再针对供应方真实 API 做合同测试和受控联调。
